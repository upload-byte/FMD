# FMD
FMD (Free Memoric Database), allows you, to store data into this free database, without a hassle. I will warn you that, this database is NOT secure. Alternatives to this database include, node.js, sql, e.t.c. and *local storage* is always an option too. You will find the database, inside the storage folder. There is a password & username file for the data. The names are **passwords.json** & **usernames.json**. Other files, are either README.md (what you're currently reading) or to upload to passwords.json or usernames.json.
